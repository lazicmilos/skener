# Code of Conduct

SiteTriage has adopted the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone who takes part in the project: in issues, pull
requests, discussions, reviews and any other project space.

## Reporting

If you experience or witness unacceptable behaviour, report it to the maintainer,
[lazicmilos](https://github.com/lazicmilos), through GitHub. GitHub has no private messages, so if
the matter should not be discussed in public, open a short issue that only asks the maintainer to
contact you, without any details, and the maintainer will arrange a private channel. Reports are
handled confidentially.

The maintainer is responsible for clarifying and enforcing the code of conduct, and follows the
enforcement guidelines of the Contributor Covenant.
